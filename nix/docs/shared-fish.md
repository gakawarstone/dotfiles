# Общая конфигурация fish

`nix/home/gws/fish.nix` устанавливает fish, Starship и Zoxide и подключает
отслеживаемые файлы fish и `starship.toml` из снимка Nix store. Правки вступают
в силу после пересборки и активации Home Manager. Инициализация Starship и
Zoxide остаётся в `config.fish`; их fish-интеграцию Home Manager включать не
нужно. Локальные `fish_variables`, другие локальные файлы и `~/.env.fish` не
управляются модулем.

NixOS импортирует модуль через `nix/home/gws/default.nix`. Для Arch после
объединения PR #13 добавьте `./nix/home/gws/fish.nix` в список модулей
`homeConfigurations."gws@arch"`. До этого standalone-конфигурация из PR #13
сама fish не устанавливает.

Перед первой активацией проверьте существующие `~/.config/fish` и
`~/.config/starship.toml`. Если Stow владеет fish, в его локальном
`gkdots/config.py` отключите fish и аккуратно отсоедините Stow-ссылки, сохранив
локальные файлы. Stow может ссылаться на весь каталог fish: сначала сохраните
его содержимое и восстановите локальные файлы в обычном каталоге. Уберите или
сохраните отдельно конфликтующие файлы, которыми теперь управляет Home Manager.
Не удаляйте `fish_variables`. Шаблон Stow больше не включает fish по умолчанию;
существующий локальный `config.py` от этого не меняется. Аналогично передайте
`starship.toml`, если он уже установлен. После проверки можно активировать Home
Manager обычным способом на каждой машине; эта миграция сама активацию не делает.
