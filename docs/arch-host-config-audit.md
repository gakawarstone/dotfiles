# Ревизия локальных настроек Arch

Этот документ дополняет [журнал миграции](migration-dotfiles-nix.md). Цель ревизии — выяснить, какие настройки рабочего ПК пришлось бы восстанавливать вручную после переустановки и какие из них стоит описать в dotfiles.

## Что сверить

1. Начать с активных настроек в `~/.config` и пользовательских скриптов в `~/.local/bin`. Для каждого кандидата определить источник, включая цель симлинка или настройку, сгенерированную приложением.
2. Сопоставить настройки с `configs/`, `bins/` и модулями профиля `homeConfigurations."gws@arch"` из `flake.nix`. Учесть незакоммиченные изменения в основной рабочей копии dotfiles.
3. Потом проверить локальные юниты и таймеры systemd, системные настройки в `/etc` и приложения, которые пользователь устанавливал вручную. Отмечать ручные настройки, которые нужны для воспроизведения рабочего процесса.

## Как принимать решение

Для каждого кандидата выяснить, используется ли он сейчас, нужен ли на обеих машинах и чем управляется. Повторяемые пользовательские настройки можно подключить через Home Manager. Если они зависят от ПК, обсудить отдельный модуль Arch. Для системной настройки Arch определить, достаточно ли описать ручной шаг. Установку приложений оставить средствам Arch согласно договорённости о миграции.

Решения по конкретным настройкам принимаются в треде ревизии. В PR записываем согласованное решение и его причину. Секреты, профили сессий и данные приложений остаются на машине.

## На согласование

Пункты собраны после сверки с основной рабочей копией `~/dotfiles` и слияния
закоммиченных изменений `master` в ветку миграции. Обсуждаем по одному.

- [ ] **Игровой лаунчер Quickshell.** Переносить ли локальную карусель, обложки Steam,
  переключение вида кнопкой `X` и навигацию влево и вправо? Отдельно решить, нужен ли
  повторный поиск контроллера через SDL после подключения.
- [ ] **PS5 Frame Generation.** Оставить ли отдельный ручной установщик или передать
  ярлык и скрипт запуска Home Manager? Уточнить, нужны ли после переустановки
  оба способа запуска Chiaki.
- [ ] **Панель Quickshell на ПК.** Согласовать локальные настройки Pomodoro, HSFL VPN
  и видимости Wi-Fi и остальных индикаторов, затем обновить описание панели.
- [ ] **Правила Hyprland.** Переносить ли правило, которое отправляет окно
  тренера GTA3 на `HDMI-A-1`? В локальной копии профиля ноутбука отсутствуют
  уже согласованные
  правила прокрутки для рабочих столов 3 и 4. Уточнить, требуется ли изменение
  профиля ноутбука.
- [ ] **Статус PS5.** Нужна ли отдельная команда `ps5-pro --status`, если индикатор
  Quickshell уже опрашивает консоль через `ps5-status.py`?
- [ ] **Настройка Remote Play.** Решить, какие локальные заметки добавить в документацию.
  В них описаны проводной маршрут и настройки ARP, диагностика потерь пакетов,
  битрейт, настройки масштабирования и отдельный ярлык Gamescope с NIS.
- [ ] **Neovim.** Выбрать общий источник для обеих машин. Отдельная копия на ПК
  находится на `6cc0d7d`. На той же ревизии закреплён flake input. Submodule
  указывает на `ae8ee55`.
  Согласовать локальное изменение `lazy-lock.json` и Kotlin-патч NixOS.
- [ ] **WinApps.** Уточнить, используется ли он и как восстанавливать его после
  переустановки. Сейчас команды ведут в локальный `winapps-src`, а в
  `~/.config/winapps` есть `compose.yaml` и `winapps.conf`.
- [ ] **pCloud.** Уточнить, используется ли AppImage с `pcloud.desktop` в
  автозапуске и нужен ли этот запуск после переустановки. Сверить назначение
  со старой записью `rclone mount` в конфигурации X11.
- [ ] **Прежний установщик.** Сверить, покрывает ли Home Manager всё ещё нужное
  поведение локальных записей `agents` и `ps5-pro` в `gkdots/config.def.py`.
- [ ] **Заметки и макеты.** Решить, нужны ли в репозитории локальные задачи из
  `.tasks`, заметка о восстановлении Herdr после перезагрузки и три HTML-макета
  лаунчера.
